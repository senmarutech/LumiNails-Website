# 💅 LumiNails Website

---

A web-based nail art website project focused on delivering a modern, elegant, and visually engaging user interface.
This project was built as part of my learning journey in React, where I developed the application while following and adapting a tutorial for educational purposes.

The website highlights aesthetic design, smooth animations, and strong visual hierarchy to create an enjoyable and premium user experience.

## 🚀 Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Framer Motion for animations

## 🎯 Purpose

This project was created for learning and practice, especially to improve my skills in building interactive and animated user interfaces using React and modern frontend tools.

## 📚 Learning Source

This project was inspired and guided by a tutorial from YouTube

All credits for the original tutorial and guidance go to the creator. This project is a personal implementation and adaptation for learning purposes.

## ✨ Features

- Elegant and modern UI design
- Smooth animations with Framer Motion
- Responsive layout for all devices
- Clean and structured visual hierarchy
- Interactive components
